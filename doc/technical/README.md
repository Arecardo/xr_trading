## 建议落地顺序

1. 统一品牌、导航和领域术语。
2. 建立资产目录、投资组合、组合成员和持仓模型。
3. 迁移历史 `stock_pools` 数据和 API。
4. 建立美股与加密数据采集及质量检查。
5. 实现组合估值、目标权重、策略和风控。
6. 完成组合级回测与报告。
7. 接入长桥模拟盘，完成订单、成交和持仓对账。
8. 连续运行并评估小资金实盘条件。

## 统一设计原则

- 产品文案统一使用“XR-Trading 量化投资研究平台”。
- 投资组合是核心业务对象，候选资产列表只是组合的一部分。
- 使用内部 `asset_id` 统一资产，不以 symbol 作为唯一键。
- 策略输出目标权重与调仓建议，任何订单都必须通过组合级和订单级风控。
- 研究、回测、模拟和实盘严格隔离，实盘必须显式授权。
- 美股与加密共用领域模型，但交易日历、精度、费用和风险规则由市场适配层处理。
- 所有信号、审批、风控、订单、成交、持仓和估值均可追溯和对账。
