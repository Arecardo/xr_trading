# 风控模块技术文档

## 1. 模块目标

风控模块是订单提交前的强制检查层。任何交易建议在进入交易执行模块前，都必须生成可审计的风控结果。

## 2. 输入

- 交易建议。
- 投资组合、组合成员和目标权重。
- 当前账户权益。
- 当前现金。
- 当前持仓。
- 未完成订单。
- 当日已实现和未实现盈亏。
- 历史权益曲线。
- 资产交易状态与组合成员状态。
- 风控配置。
- 交易环境配置。
- 重大事件日历。

## 3. 风控配置

```yaml
risk:
  max_equity_asset_pct: 0.20
  max_crypto_asset_pct: 0.15
  max_crypto_exposure_pct: 0.30
  max_total_exposure_pct: 0.80
  min_cash_pct: 0.20
  max_positions: 5
  max_trade_risk_pct: 0.01
  max_daily_loss_pct: 0.015
  max_drawdown_warn_pct: 0.05
  max_drawdown_stop_pct: 0.10
```

## 4. 检查项

| 检查项 | 拦截条件 |
| --- | --- |
| 交易时间 | 不在允许交易窗口 |
| 环境 | live 未显式开启或凭据不合法 |
| 组合状态 | 非 `active` 组合不允许新增风险 |
| 资产与成员状态 | `candidate`、`restricted`、`paused`、`blacklist` 不允许买入 |
| 单资产仓位 | 超过对应资产类型上限 |
| 类别敞口 | 美股、ETF、加密或现金配置突破组合预算 |
| 市场与通道 | 资产市场无可用适配器或能力不匹配 |
| 总持仓 | 超过 `max_total_exposure_pct` |
| 最大持仓数量 | 超过 `max_positions` |
| 单笔风险 | 超过 `max_trade_risk_pct` |
| 单日亏损 | 超过 `max_daily_loss_pct` |
| 总回撤 | 超过警戒线或停止线 |
| 订单冲突 | 存在同方向未完成订单 |
| 人工确认 | live 或配置要求确认但未确认 |
| 重大事件 | 接近 FOMC、CPI、财报、监管或加密市场异常窗口 |
| 流动性与精度 | 交易量、价差、最小订单量或精度不合要求 |

## 5. 风控输出

```json
{
  "run_id": "2026-05-31-pre_market-001",
  "portfolio_id": "pf_growth_us_crypto",
  "passed": false,
  "blocked_reason": "max_position_pct_exceeded",
  "symbol": "NVDA",
  "action": "buy",
  "requested_weight": 0.3,
  "limit": 0.2,
  "risk_version": "risk_v0.1.0",
  "created_at": "2026-05-31T08:00:01+08:00"
}
```

## 6. 风控结果分类

| 结果 | 含义 | 后续动作 |
| --- | --- | --- |
| passed | 通过 | 可进入确认或执行 |
| warning | 接近阈值 | 降低仓位或请求确认 |
| blocked | 拦截 | 禁止提交订单 |

## 7. 单笔风险计算

做多现货交易可用以下近似方式：

```text
单笔风险金额 = abs(入场价 - 止损价) * 资产数量
单笔风险比例 = 单笔风险金额 / 账户权益
```

如果没有显式止损价，MVP 可按资产类别配置 ATR 倍数估算：

```text
止损价 = 入场价 - 2 * ATR
```

买入前必须保证单笔风险比例不超过配置阈值。

## 8. 审计要求

风控必须记录：

- 输入交易建议。
- 检查时账户快照。
- 检查时持仓快照。
- 命中的规则。
- 通过或拦截原因。
- 风控配置版本。
- 风控代码版本。

## 9. 推荐流程

1. 校验交易环境。
2. 校验组合、资产和成员状态。
3. 校验组合级、资产类别级风险。
4. 校验账户、持仓、现金和流动性风险。
5. 校验订单冲突。
6. 校验重大事件窗口。
7. 校验人工确认。
8. 输出风控结果并落地。

## 10. 测试点

- 单一资产目标仓位超过对应资产类别上限时必须拦截。
- 加密资产总敞口超过组合预算时必须拦截。
- 总持仓超过 80% 时禁止新增。
- 当日亏损超过阈值时禁止新开仓。
- 总回撤超过停止线时禁止所有新增仓。
- `live` 未人工确认时必须拦截。
- 同一 `asset_id` 已有未完成同方向订单时，新订单应拦截或合并。
- 加密适配器未启用时，任何加密真实订单必须拦截。
