# 回测数据与指标实施计划

> 对应里程碑：M2'（回测数据与指标）。
> 依赖：M0（契约冻结）；可与 M1/M2 并行——回测数据装载直接走行情服务查询 API，不依赖 backend 领域模型落地进度。

## 1. BT-001 历史数据装载

| ID | 状态 | 依赖 | 输出 | 测试与完成条件 |
| --- | --- | --- | --- | --- |
| BT-001 | TODO | DEC-001、DEC-002 | 从 `market-info-service` 读历史日线（后续可扩小时线），装载为回测输入；按 UTC 自然日对齐美股交易日历与加密 24/7 时间轴——美股非交易日沿用上一交易日收盘价并标记 `price_status: stale`，加密照常取当日数据 | 美股休市不误报缺失、且正确标记 `stale`；加密按 24/7 估值；无未来数据；可为标的清单提供按自然日对齐的历史序列，全年 365 天无跳空 |

| ID | 状态 | 依赖 | 输出 | 测试与完成条件 |

## 3. M2' 退出门禁

- 标的清单的历史序列按自然日对齐，非交易日的 `stale` 标记贯穿到指标计算层（指标计算需明确说明如何处理 `stale` 输入，例如沿用上一有效值而不重新计算）。
- 全部指标有固定样本单测，边界情况（数据不足、缺口）有明确降级行为而非崩溃或静默错误值。
- 不使用未来数据、未来成分或未在当时可得的修订数据。
