# P2 回测引擎（RM2）

> 目的：以零资金风险验证策略 + 风控逻辑，并**倒逼策略/风控接口定型**。回测须复用与 paper/live 相同的策略与风控代码，避免研究/执行逻辑分叉。
> 依赖：RM0（DEC-001/002/003）。可与 RM1 并行（数据装载可先用行情服务查询，落地估值再对齐 RM1 模型）。
> 参照：`doc/technical/08_backtest_engine.md`、`04_analysis_modules.md`、`05_strategy_service.md`、`06_risk_service.md`。
> 状态：TODO。最近更新：2026-08-05。

## 任务清单

### BT-001 历史数据装载 — P2
- 依赖：DEC-001、DEC-002
- 输出：从 `market-info-service` 读历史日线（后续可扩小时线），装载为回测输入；按 **UTC 自然日**（DEC-002）对齐美股交易日历与加密 24/7 时间轴——美股非交易日沿用上一交易日收盘价并标记 `price_status: stale`，加密照常取当日数据。
- 测试：美股休市不误报缺失、且正确标记 `stale`；加密按 24/7 估值；无未来数据。
- 完成条件：可为标的清单提供按自然日对齐的历史序列，全年 365 天无跳空。

### BT-002 指标计算库 — P2
- 依赖：BT-001
- 输出：日收益、MA(5/20/50)、均线趋势、RSI、ATR、成交量变化、相对 20 日高低点位置、相对基准强弱。
- 测试：每个指标有固定样本单测；K 线不足 50 日时降级处理。
- 完成条件：指标输出符合 `04_analysis_modules.md` 定义。

### BT-003 事件驱动回测循环 — P2
- 依赖：BT-001、BT-002、DEC-003
- 输出：按 UTC 自然日时间步 加载行情→更新市值→生成指标/评分→策略信号（stale 标价日不生成新美股信号）→风控→模拟撮合→更新持仓现金→折算基础货币→记录日权益。撮合含手续费、滑点、限价触发规则、最小交易量。**成交精度按环境区分（2026-08-05 修订，见需求文档 §5.1.1）**：`research`/`backtest` 模式下成交数量按 `Decimal` 任意精度记录，不受 `lot_size`/`quantity_scale` 约束；引擎需同时支持一个「受限」运行模式（按目录 `lot_size` 整股/步长取整），用于与不受限模式对比跟踪误差（见下方验证任务）。精度规则读自行情服务 Instrument 目录（不硬编码），数据缺失/过期时该标的当期 fail-closed 且记录原因（DEC-003）。
- 测试：手续费/滑点影响收益；单资产/类别权重与最大持仓数约束生效；固定输入结果可复现；精度数据缺失时对应标的不撮合而非静默使用默认值；同一输入分别以「不受限」和「受限（按 `lot_size` 取整）」两种精度模式跑通，两者结果均可复现。
- 完成条件：撮合规则写入回测报告，与实盘执行假设一致；报告需注明本次回测使用的是受限还是不受限精度模式。

### BT-003a 碎股跟踪误差对比验证 — P2（BT-003 之后，RM3 前必须完成）
- 依赖：BT-003、BT-006（绩效对账）
- 背景：DEC-003 最初假设 `paper` 也可用不受限小数，后经 BE-004a 采集长桥真实精度（NVDA/QQQ `lot_size=1`，不支持碎股）确认 `paper` 走长桥模拟盘真实下单接口、必须整股，与最初假设矛盾（见需求文档 §5.1.1 修订说明）。
- 输出：用同一组历史数据、同一策略，分别跑「不受限小数」与「受限整股（`lot_size=1`）」两轮 NVDA/QQQ 回测，对比目标权重跟踪误差、收益率、回撤等指标的实际差异。
- 测试：两轮回测均可复现；差异报告包含具体数值对比，不是定性描述。
- 完成条件：产出书面结论——是否需要提高初始资金、调整标的选择，或接受该跟踪误差进入 RM3 paper 阶段；结论写回需求文档 §5.1.1 与 `01_decisions.md` DEC-003。

### BT-004 策略接口 + 简单规则策略 — P2
- 依赖：BT-002
- 输出：定义策略接口（输入分析结果+组合状态，输出资产评分/目标权重/调仓建议，不直接下单）；实现一条简单规则策略（如分资产类型加权评分 + 阈值决策）。
- 测试：权重和不为 1 拒绝运行；restricted/blacklist 不生成买入；缺技术指标不生成买入。
- 完成条件：策略接口可被回测与 paper 共用。

### BT-005 风控接口（回测复用）— P2
- 依赖：BT-004
- 输出：定义订单/组合级风控接口；实现单资产/类别敞口、总持仓、最大持仓数、单笔风险、现金下限、回撤停止线等检查；不可实时复用的检查（交易时间、人工确认）在回测中用替代实现并标记。
- 测试：目标仓位超类别上限拦截；加密总敞口超预算拦截；回撤超停止线禁止新增。
- 完成条件：同一风控代码可被回测与 paper/live 调用。

### BT-006 绩效指标 + 可复现性/对账 — P2
- 依赖：BT-003
- 输出：总收益、最大回撤、年化波动、Sharpe、Sortino、胜率、盈亏比、换手率、基准对比；逐日对账目标权重/持仓/现金/汇率/净值。
- 测试：相同输入产出相同结果；权益曲线可逐日对账。
- 完成条件：报告不只展示收益率，含完整风险指标。

### BT-007 回测报告 — P2
- 依赖：BT-006
- 输出：Markdown/HTML 回测报告（配置、撮合假设、绩效、交易记录、风控事件），落 `reports/backtest/`。
- 测试：报告含风险指标与撮合假设说明。
- 完成条件：符合 `09_logging_reports.md` 模板。

## 退出条件（RM2）

固定输入回测结果可复现；逐日对账通过；策略与风控接口已定型并可被 paper 复用；报告含完整风险指标。
